How the pipeline fits together

Three entry points, one shared engine for two of them, and a forecaster that runs entirely on its own. This reflects the repo as of the 2026-09-07 cleanup.

Teal — analyze / GUI path
Amber — forecast path (independent)
Dashed — reads config or existing data
Both CLI subcommands and the GUI are documented in README.md; analyze needs real API keys in .env (currently unset — it fails cleanly with a named Missing configuration error rather than crashing). forecast needs no keys and runs on whatever event CSVs already exist locally.
