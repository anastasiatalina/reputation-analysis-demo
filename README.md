### PyProject — Reputation Analysis (to-be refactor in progress)

This folder is a **publishable snapshot** of the project meant to demonstrate architecture and code logic.

## What is intentionally NOT included
- Any `.env` files or secrets
- Any virtual environments, caches, or IDE files (e.g. `.venv/`, `__pycache__/`)

## What IS included
The CSVs and PNG under `data/` and `assets/` are **mock data** generated by
`app.mocks.generate` (see below) — synthetic events with `example.com` URLs, not real
scraped content. They ship with this snapshot so the demo runs and the GUI/forecast have
something to show without any API keys.

## What this project does

[View presentation](./reputation-analysis.pdf)

- Collects events about a company (news, Reddit, analyst insights, stock news).
- Computes a sentiment-based reputation score per event.
- Produces merged events CSV + stock prices CSV.
- Provides a Flet UI (`python -m app.ui`) and a CLI (`python -m app ...`).
- Builds a weekly ARIMA forecast (`app/forecasting/forecast.py`) and saves the plot in `assets/`.

[Pipeline map](./pipeline-map.png)

## Setup

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Configure environment variables (copy from `ENV_EXAMPLE.txt` into your local `.env` or export them):
- `FMP_API_KEY`
- `NEWSAPI_KEYS` (comma-separated)
- `BENZINGA_TOKEN`
- `REDDIT_CLIENT_ID`, `REDDIT_CLIENT_SECRET`, `REDDIT_USER_AGENT`

## Mock data (optional)

Generate mock CSVs and a placeholder forecast plot (no API keys required):

```bash
python -m app.mocks.generate --company Apple --ticker AAPL --days 90
```

Force regeneration (overwrite existing mock files):

```bash
python -m app.mocks.generate --company Apple --ticker AAPL --days 90 --force
```

## Run (GUI)

```bash
python -m app.ui
```

## Run (CLI)

Analyze:

```bash
python -m app analyze --company Apple --ticker AAPL --days 90
```

Forecast:

```bash
python -m app forecast --file1 data/raw/NO_1.csv --file2 data/raw/Apple_{YYYY-MM-DD}_2years.csv --weeks 12
```

## Outputs
- Merged events CSV: `data/processed/combined_output_{YYYY-MM-DD}_{Company}_{days}days.csv`
- Stock prices CSV: `data/processed/stock_data_{YYYY-MM-DD}_{Company}_{days}days.csv`
- News CSV: `data/processed/news_data_{YYYY-MM-DD}.csv`
- Reddit JSON: `data/processed/reddit_data_{YYYY-MM-DD}.json`
- Weekly dataset: `data/processed/weighted_weekly_data.csv`
- Forecast plot: `assets/forecast_plot_12_weeks.png`
